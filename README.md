# Sendar Replit mock review — experimental

Published by Sendar. No Replit affiliation, approval, audited listing or actual Replit host acceptance is claimed.

This standalone repository places the exact **0.1.7** review packet at the project root for Replit GitHub import. It is a review artifact, not a production email application or a native integration. It does not replace the released Sendar skills or any partner application.

## Import and run

The official public-repository rapid-import route is:

https://replit.com/github.com/Thutos/sendar-replit-review

**Not yet host-tested.** Before opening/importing, resolve the existing owner task: confirm a no-additional-charge path and check the original partner application receipt. Prefer the existing disposable review project and frozen ZIP if importing would create an unnecessary new project. Do not grant GitHub access, accept new terms, deploy, enable Agent, buy credits or attach credentials. If Replit asks for any of these, stop. The rapid-import link has been constructed from documented syntax; its actual Replit behavior has not been verified.

Node >=20; no dependencies or API keys. Run starts `node preview.mjs` on port 3000. The page runs mocked recipes and offers a source-hashed JSON download. All CLI examples are synthetic. `npm test`, `npm run review`, and `npm run test:preview` can be run separately. No live customer test sends.

Retain project URL, dated Preview/Console evidence and the downloaded JSON. Actual Agent skill discovery is a **separate** acceptance item and requires its own authorized no-charge context. A page or JSON report is not proof of host origin, directory submission or approval.
